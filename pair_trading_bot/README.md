# Python Pair Trading Bot for MetaTrader 5

This project implements a pair trading strategy bot that interacts with the MetaTrader 5 (MT5) platform. It uses statistical arbitrage techniques, specifically focusing on cointegration to identify trading opportunities between two correlated assets.

## Features

- **Pair Trading Strategy**: Identifies two cointegrated assets and trades the spread.
- **Cointegration Analysis**: Uses the Johansen test to check for cointegration between asset pairs and calculates the hedge ratio.
- **Spread Calculation**: Computes the spread between the two assets based on the hedge ratio.
- **Z-Score Calculation**: Normalizes the spread using Z-scores to identify entry and exit points.
- **Money Management**:
    - Calculates position sizes based on account balance, risk percentage, and stop-loss levels.
    - Determines stop-loss and take-profit levels based on Z-score thresholds.
- **MetaTrader 5 Integration**:
    - Connects to an MT5 account.
    - Fetches historical price data.
    - (Simulated) Trade execution: The current version simulates trade execution. Real trade execution would require enabling and testing MT5 order commands.
- **Logging**: Comprehensive logging for monitoring bot activity and troubleshooting.
- **Modular Design**: Code is organized into modules for utility functions, money management, and the core trading bot logic.
- **Unit Tests**: Includes a suite of unit tests for verifying the correctness of individual components.

## Prerequisites

- Python 3.7+
- MetaTrader 5 Terminal installed and running.
- An active MetaTrader 5 account (demo or live).
- The `MetaTrader5` Python package. On Windows, this is typically installed alongside the MT5 terminal. For Linux/macOS, setup can be more complex and might require Wine or alternative solutions if direct installation isn't supported. *Note: The bot includes a mock MT5 interface for development and testing in environments without a live MT5 connection.*

## Setup

1.  **Clone the repository (if applicable) or download the files.**
    ```bash
    # git clone [repository_url]
    # cd pair_trading_bot
    ```

2.  **Create a virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    *Note on MetaTrader5 library*: If `pip install MetaTrader5` fails (especially on non-Windows systems), you may need to ensure the library is correctly installed and accessible from your Python environment, often by copying it from the MT5 terminal installation directory. The bot is designed to run with a mocked MT5 interface if the actual library is unavailable, allowing core logic testing.

## Configuration

Open `pair_trading_bot/main.py` and modify the `config` dictionary with your desired parameters:

-   `symbol1`, `symbol2`: The two symbols for pair trading (e.g., "AUDCAD", "NZDCAD").
-   `timeframe`: Chart timeframe (e.g., "H1", "D1").
-   `lookback_period`: Number of historical bars for cointegration and Z-score calculation.
-   `entry_z_threshold`, `exit_z_threshold`, `stop_loss_z_multiplier`: Z-score thresholds for trading decisions.
-   `account_balance`: Your account balance (used for simulated position sizing).
-   `risk_percentage`: Desired risk per trade (e.g., `0.01` for 1%).
-   `pip_value_leg1`, `pip_value_leg2`: The monetary value of 1 pip movement for 1 standard lot of `symbol1` and `symbol2`, respectively, in your account currency. **These are critical for correct position sizing and must be determined accurately for your broker and account.** The current bot uses `pip_value_leg1` as a proxy for the spread's pip value in its simplified sizing model.
-   `run_interval_seconds`: How often the bot checks for trading opportunities.

For a production deployment, consider moving this configuration to an external file (e.g., JSON, YAML, .env).

## Running the Bot

1.  **Ensure your MetaTrader 5 terminal is running and you are logged into your account.** (Required for live data and real trading; mocked operation is possible without it).
2.  **Navigate to the project's root directory (`pair_trading_bot/`)** if you are not already there.
3.  **Run the main script:**
    ```bash
    python main.py
    ```
    Or, if your project structure and PYTHONPATH are set up to treat `pair_trading_bot` as a package:
    ```bash
    python -m main  # (If main.py is at the root of an importable package)
    ```

The bot will start running, periodically checking for trading signals and (simulating) trades based on its logic. Logs will be printed to the console and potentially to files in the `logs/` directory if file logging is configured.

Press `Ctrl+C` to stop the bot gracefully.

## Running Unit Tests

To run the unit tests, navigate to the project root directory (`pair_trading_bot/`) and run:

```bash
python -m unittest discover -s tests -v
```
Or, if `tests` is directly under `pair_trading_bot` and you are in the parent of `pair_trading_bot`:
```bash
python -m unittest discover -s pair_trading_bot/tests -v
```

The tests use mocks for MT5 interactions and helper functions, allowing them to run without a live MT5 connection.

-   **Thoroughly test any trading bot in a demo environment before using it with real money.**
